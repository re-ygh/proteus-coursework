Selected circuit projects from one university course, organized as one folder per exercise/project. Each folder contains the original Proteus project, an exported schematic preview, and a short README.

## Open a project

Use Proteus 8 Professional to open the `.pdsprj` file inside the chosen folder. The `schematic.svg` preview can be viewed on GitHub without installing Proteus. The simulation checks above only confirm that each copied project starts without logged warnings or errors; they do not validate every input or the complete intended behavior.

`DC_1.pdsprj` and `TETRIS_AINAL.pdsprj` are not included yet because Proteus reports logic-contention warnings when they are simulated. Two blank sheets, local workspace files, backups, and an archive duplicating circuit files are also excluded. The original university files remain in the local source folder.
